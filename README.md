# BunnyEngine
This project focuses on developing a game engine built on DirectX-based rendering, with the final objective of creating a 3D game.

<img width="1915" height="1105" alt="engine_deom_1" src="https://github.com/user-attachments/assets/d573d6f2-58ae-4f82-8cad-788f42bc42a1" />

## Render Style
- Based on deferred rendering
- PBR lighting is combined with toon shading
- Object outlines are rendered using a Sobel filter
<img width="1907" height="1062" alt="engine_demo_2" src="https://github.com/user-attachments/assets/7a905726-1233-43bf-8cbe-85a3890cf5c2" />

## Physics system
- Physics system used the ReactPhysics3d library

## Key manual
- Player Movement : Arrow keys
- Dash : Z
- Attack : X
- Jump : C
## Editor mode
- Toggle Editor mode : F3
- Scene Change : F4
### Editor camera control
- Movement : W A S D
- Up & Down : Q E
- View point Control : Move mouse while holding down wheel
